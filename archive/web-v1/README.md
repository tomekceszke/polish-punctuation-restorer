# Landing page, version 1 (2026-07 to 2026-09)

The original one-page design, retired on 2026-09-10 in favour of the feature-article
layout now in `web/`. Kept here so it can be brought back or borrowed from; it is not
deployed (GitHub Pages publishes `web/` only).

To view it locally, copy `index.html` and `style.css` into `web/` alongside the shared
files it still expects there: `i18n.js`, `model.js`, `script.js` and `model/`. The shared
`script.js` kept both hooks this page needs (`#heroNet`, whole-page punctuation accent),
so it runs unchanged.
